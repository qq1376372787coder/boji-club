# 薄肌俱乐部管理后台

当前源码与账号服务共用数据库，入口为 https://api.gongxiang.cloud/admin/ 。正式域名必须先正确解析到服务器。

部署使用本目录上一级的 `deploy.sh`，基础结构为 `schema.sql`、`admin-schema.sql`、`club-schema.sql` 和 `migrate-20261001.php`。运行前应备份数据库、配置与现有媒体目录；保留 `config.php`、管理员账号密码、用户照片、奖励图片和运行状态。不要把密钥或用户数据复制到交付包。

`deploy.sh` 以服务器 `/opt/bojiclub-account` 为工作目录，需要 root；新环境使用脚本要求的环境变量提供数据库密码和OTP签名密钥。现有管理员由数据库保存，重复部署不重置密码。新环境还需由服务器管理员建立首位管理员；脚本不会自动创建或输出登录密码。

功能包括成员资料与已同步记录、账号禁用/恢复、会员人工调整及事件记录、AI状态、活动任务、徽章/实物目录和申领。普通账号恢复不能撤销已受理的注销流程。后台只能展示已同步内容，不代表手机全部本机记录。身体复盘照片不进入管理后台。

AI暂停只阻止新任务；已接收任务继续运行。会员真实购买需完成RevenueCat/App Store配置与沙盒验收。通知页面当前记录测试发送，没有完成APNs远程推送；App本地提醒是不同能力。

维护时分别检查数据库与AI健康状态。备份状态为 `runtime/backup-status.json`；备份成功记录不能替代恢复演练。数据库备份计划为北京时间03:25、保留14天，最终以服务器实际定时配置为准。

奖励上传支持JPG、PNG和WebP；配套纪念品SVG的发布副本转换成PNG，原SVG只作源资源。部署应保留并合并 `admin-media`，不能清空现有自定义图片。修改目录类型时，实物必须填写有效库存；已发布活动的门槛/库存修改继续受服务端限制。

发布前完成PHP检查、隔离接口回归、管理员浏览器操作、正式域名网络验收，以及iOS完整编译和真机关键流程测试。历史记录与测试结果保存在项目各audit目录，仅代表记录当时的版本。
