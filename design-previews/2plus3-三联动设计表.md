# 三联动设计表 · 动效 × 震动 × 音效（界面设计 · 2026-11-08）

用户新增要求：华丽感要做足，**动效 + 震动 + 音效三层同一拍触发**。本表与《2plus3-全页面组件规格表》同格式，逐条列；苹果开发照表施工，后端开发按音色定位合成素材。

配套：触感已有 `BojiHaptics` L1–L4（DesignTokens.swift:318），动效已有 `BojiMotion2` 四档（BojiDesignSystemV2.swift:404）。**本表不新造档位，只做映射**。

---

## 1. 音色定位（先定调，后端开发照此合成）

**一句话**：像「清晨金属与木头」——干净、有分量、不游戏化。不要电子嘟嘟声、不要合成器滑音、不要鼓点。

| 项 | 规格 |
|---|---|
| 风格 | 木质打击 + 金属泛音的短促点缀；暖、干脆、有回响尾巴（0.05–0.12s 衰减） |
| 基频区间 | 600–1800 Hz（中高频，避免低频轰头、也避免刺耳） |
| 时长 | 0.05–0.60s，绝大多数 ≤0.15s |
| 格式 | 48kHz / 16bit / 单声道 / `.caf`（iOS 原生，无解码延迟） |
| 响度 | 峰值 -6 dBFS，整体比系统音效低 3 dB，不盖过说话 |
| 合成方式 | 正弦基频 + 2–3 个泛音 + 指数衰减包络（ADSR 的 AR 段）；无采样、无版权 |
| 入包 | `BojiClub/Sounds/boji_*.caf`，加入 target；用 `AVAudioPlayer` 预加载（`prepareToPlay`） |
| 开关 | 设置加「音效」开关（默认开）；**尊重系统静音开关**（`AVAudioSession` 的 `silentMode` 行为） |
| 降级 | 减少动态效果 / 静音 / 低电量：只保留触感，音效静音；**功能不受影响** |

## 2. 六个基础音色（后端开发交付 6 个 .caf）

| 编号 | 名称 | 音色描述 | 合成要点 | 时长 |
|---|---|---|---|---|
| S1 | `boji_tap` | 轻触点：木头轻叩 | 基频 1150 Hz + 泛音 2300/3450，快速衰减 | 0.07s |
| S2 | `boji_set_done` | 一组完成：金属「咔」+ 木尾 | 基频 980 Hz + 金属泛音 2940/3920，0.05s 起音 + 0.10s 衰减 | 0.15s |
| S3 | `boji_milestone` | 里程碑：两音上行（低→高） | 880 Hz → 1320 Hz 双音，间隔 0.06s，带一点共鸣 | 0.28s |
| S4 | `boji_workout_done` | 训练完成：三音上行小和弦 | 660 / 880 / 1320 Hz 依次叠入，末尾 0.15s 混响感 | 0.55s |
| S5 | `boji_rest_tick` | 组间计时：极轻木鱼 | 基频 1500 Hz 单点，短促无尾音（避免频繁播放烦人） | 0.05s |
| S6 | `boji_error` | 错误/失败：低沉双音下行 | 320 Hz → 240 Hz，闷、短、无金属感 | 0.22s |

红线：S1/S5 每次交互都可播（轻、短）；S2–S4 每个事件最多播一次，不循环；S6 只在真错误时播。

## 4. 同步性规格（关键，避免「三层各说各话」）

1. **同一拍触发**：动效、`BojiHaptics`、音效在**同一个 action 闭包**里连续调用，中间不插异步；系统触感与 `AVAudioPlayer.play()` 都是低延迟路径，误差 <30ms。
2. **一屏最多一个音效**：并发事件（如快速点按）只播最后一次，或设 0.05s 去抖；不允许叠声。
3. **音量一致性**：所有素材归一化到同一感知响度（峰值 -6 dBFS，LUFS 相近），避免有的轻有的炸。
4. **预加载**：App 启动后预加载 6 个 player（`prepareToPlay`），避免首次播放延迟。
5. **设置开关**：`设置 → 音效`，关闭后只停音效、触感与动效照常；**静音开关（硬件）优先**，硬件静音时全部静音（这是 iOS 默认行为，不用额外判断，但要实测确认）。
6. **减动效**：减少动态效果开启时，动效降 0.12s 交叉淡入，**音效与触感保留**（用户要求「不缺功能」）。

## 6. 走查口径（界面设计逐批执行）

每批核对：①每个关键交互三层齐备（动效/震动/音效）且同一拍；②音效不叠声、不超 0.6s；③静音开关与设置开关生效；④减动效下音效触感仍在；⑤无自绘音效控件（用系统 `AVAudioPlayer`）。真机四项（深色/大字号/减弱动态/增强对比度）+ 静音开关实机复跑。
