## 0. 设计语言总纲（所有页面共用）

### 0.1 三层结构
| 层 | 名称 | 材质 | 用在哪 |
|---|---|---|---|
| L1 | 内容面 | 不透明 `cardSurface`（浅 `#FFFFFF`/深 `#1A1C20`） | 列表行、卡片、表单 |
| L2 | 玻璃浮件 | `clubGlassEffect`（iOS 26 原生 glassEffect / iOS 17-25 磨砂） | 底部坞、悬浮条、Hero、弹层面板 |
| L3 | 强调玻璃 | `clubNativeGlassButton(prominent:true)` | 每屏唯一主操作 |

**红线**：每屏玻璃件 ≤3（普通页 ≤1）；玻璃下必须有内容层（视频/图片/列表）；内容层不加玻璃。

### 0.2 排印系统（新增 Token：`BojiFont` 扩展档）
| 档 | 字号/字重/字距 | 用途 |
|---|---|---|
| `.display` | 88pt / 800 / -3pt / 等宽数字 | 状态数字、进度大数字（首页 88、训练 3/12、记录 80） |
| `.editorial` | 76pt / 800 / -3.5pt / 等宽数字 | 记录页当前值、训练完成训练量 |
| `.hero` | 52pt / 800 / -2pt | Hero 数字（视频上） |
| `.cardTitle` | 20pt / 700 / -0.4pt | 卡片标题（现有） |
| `.section` | 17pt / 700 | 区块标题（现有） |
| `.body` | 17pt / 400 | 正文（现有） |
| `.caption` | 13pt / 400 | 辅助说明（现有） |

数据块规范：大数字 + 下方 1pt 细分隔线（`BojiColor.divider`）+ 标签小字；**不用图标汤**，图标只在导航/操作位出现。

### 0.3 组件规格（全页面通用）
| 组件 | 规格 |
|---|---|
| 主操作 | 全宽 54pt 白胶囊（`clubNativeGlassButton(prominent:true)`），或底部玻璃坞内 44pt 按钮；**每屏仅一个** |
| 次操作 | 文字按钮（`borderless`）或系统 `.bordered`，不得与主操作同权重 |
| 卡片 | `cardSurface` + 圆角 24 continuous + 阴影 y5/18/5%（内容面，无玻璃） |
| 数据块 | 大数字 + 细分隔线 + 标签，无卡片描边 |
| 列表 | `List(.insetGrouped)` + `clubListSurface()`，行高 ≥44 |
| 输入 | 原生 `TextField` + 数字键盘 + 键盘工具条「收起」 |
| 步进 | 系统 `Stepper`（重量 2.5kg / 次数 1） |
| 分段选择 | 系统 `Picker(.segmented)` |
| 弹层 | 系统 `sheet` + `presentationDetents`，不自绘 |
| 完成态 | 系统 `checkmark.circle.fill` + `symbolEffect(.bounce)`，包 reduceMotion |
| 动效 | `BojiMotion2`（entrance 0.35/0.85 + stagger 0.05；celebrate 0.52/0.74 一次性）；减动效降 0.12s 交叉淡入 |

### 0.4 文案口径（全页面）
禁军事黑话（战备/战术/简报/综合充能/神经负荷/超量恢复/恢复窗口），用教练口吻短句；用户已懂的词（组数、次数、蛋白质、静息心率、体脂）保留。逐条对照见 [BUILD140-文案重做对照与三方案样例.md](BUILD140-文案重做对照与三方案样例.md)。

| 项 | 现状 | 2+3 目标 |
|---|---|---|

### 1.1 三个 Tab 的图标与标题（Chief 点名，落实现直接用）

| Tab | 标题（10pt 系统字） | SF Symbol | 选中态 | 说明 |
|---|---|---|---|---|
| 今天 | 今天 | `house` | `house.fill` | 首页（ClubAIShell 内容），原生大标题「今天」 |
| 训练 | 训练 | `figure.strengthtraining.traditional` | 同左（系统自动加粗/填充） | 训练中 + 训练完成 + 记录登记（原记录三分类横翻收进此 tab 内部） |
| 记录 | 记录 | `list.bullet.rectangle` | 同左 | 训练回顾 / 饮食 / 身体 / 报告（原 ClubRecordsHub） |

规范：标题用系统 tab 栏默认字号（约 10pt），**不自绘字号**；图标只用 SF Symbols，不自绘；iOS 26 由系统渲染悬浮玻璃 tab bar，iOS 17 走系统原生样式，页面层不写 `#available`。

### 1.2 底部坞的归属（Chief 点名）

**结论：底部坞只归属「训练」tab，且不跨 tab；其他两 tab 一律用全宽主按钮，不设坞。**

| Tab | 底部形态 | 理由 |
|---|---|---|
| 今天 | 无坞。主操作＝全宽 54pt 白胶囊「开始今日训练」 | 首页是决策屏，主操作必须突出；坞会与卡片抢视觉 |
| 训练 | **玻璃坞（L2）**：左计时大数字 + 右 44pt「完成这组」 | 训练中最高频动作，手不用移到屏幕底部中央；计时与操作同屏 |
| 记录 | 无坞。主操作＝全宽 54pt「保存这一组」 | 表单页，保存是明确终点；坞会压住键盘区 |

补充：训练 tab 的坞是**页面级安全区浮件**（`safeAreaInset(edge: .bottom)`），不进 tab bar；切 tab 即消失，符合「每屏一个主操作」。若训练完成页要收尾，用系统 `sheet` + 全宽按钮，不新增坞。

## 4. 走查口径（界面设计逐批执行）

每批按本表逐页核对：①玻璃件数量与位置（内容层 0 玻璃）；②每屏主操作唯一；③排印档位与数据块规范；④文案无黑话；⑤减动效/增强对比度降级；⑥原生组件无自绘。真机四项（深色/大字号/减弱动态/增强对比度）实机复跑。
