## D. 走查方式

1. **源码级**（每批交付即做）：按 A/B 表逐条核实现，列出不达标处。
2. **真机级**（出包后）：深色 / 大字号 / 减少动态 / 增强对比度四项 + **静音开关** + 音效开关，实机复跑。
3. **性能级**：滚动 CPU Time 与启动时间对比基线 `f57f77b`（同设备 iPhone 16 Pro、Debug、CPU Time 口径），不劣化才算过。
4. 发现不达标 → 开问题单退苹果开发返工，改完复扫。
