# 动效与特效规格（界面设计 · 2026-11-09）

用户硬性要求：**原生组件不等于朴素**。该有的进场、滚动联动、按压反馈、数字滚动、转场、庆祝特效一个不能少，出品对标 **2026 年成熟大厂**的华丽高级感。
反向红线：**「干净但呆板」= 返工**。原防廉价红线照旧（无彩虹轮播 / 无无限闪动 / 无整屏转场，一屏运动元素 ≤2）——那是防土，不是防华丽。

配：`BojiMotion2` 现有 4 档（micro 0.16 / state 0.40·0.85 / transition 0.42·0.85 / celebrate 0.52·0.74）+ counter 0.35 + entrance 0.35·0.85 + stagger 0.05 + progress 0.32。**本规格新增 4 个档位**，其余复用。

---

## 一、大厂级华丽度的 5 条判据（自检用）

| # | 判据 | 反面（呆板） | 我们的做法 |
|---|---|---|---|
| 1 | **空间连续**——元素转场保持身份，从 A 位置长成 B 页面 | 直接 push 新页面，元素闪现 | 卡片→详情用 zoom 转场（iOS 18+），旧系统降 push |
| 2 | **有物理感**——弹簧带速度，不是匀速滑入 | 线性 ease 位移 | 全部 spring，禁 linear 用于位移 |
| 3 | **有层次**——滚动时前后层不同速度，不是整体平移 | 整页一起滚 | Hero 视差 0.3 倍速 + 内容正常速 |
| 4 | **有叙事**——数字滚动带单位、进度分段点亮 | 数字直接跳变 | counter 0.35 滚动 + 单位延迟 0.05 淡入 + 分段独立 spring |
| 5 | **有高潮**——全 App 唯一爆发点做到极致 | 处处平淡 | 训练完成 5 段编排，音效三拍对齐 |

## 二、动效 Token 总表（新增 4 档）

| 代号 | 名称 | 参数 | 用途 |
|---|---|---|---|
| **M1** | 微反馈 | spring(0.16, 0.78) | 按压、勾选、步进、切页签 |
| **M2** | 状态变化 | spring(0.40, 0.85) | 展开/收起、开关、进度 |
| **M3** | 转场 | spring(0.42, 0.85) | sheet、页面推入、卡片重组 |
| **M4** | 庆典 | spring(0.52, 0.74) | PR、训练完成、徽章 |
| **M5** 新 | **空间转场** | `navigationTransition(.zoom(sourceID:in:))`（iOS 18+）+ 同源 `matchedTransitionSource` | 卡片→详情、动作→动作详情、报告卡→全文 |
| **M6** 新 | **滚动视差** | 位移系数 0.30、缩放 1→0.96、不透明度 1→0.85 | Hero 视频带、封面图、大卡片 |
| **M7** 新 | **玻璃按压光影** | scale 1→0.97（M1）+ 玻璃 `interactive(true)` 系统高光 + 阴影 y8→y4、blur 24→16 | 所有玻璃操作件按下时「压进去」 |
| **M8** 新 | **数字叙事** | counter 0.35 滚动；单位 T5 延迟 0.05 淡入；变化方向决定上/下滚 | 状态分、组数、重量、训练量 |

**降级统一**：`reduceMotion` → `BojiMotion2.resolved` 降为 0.12s 交叉淡入；M5 空间转场降为系统 push；M6 视差降为静态；**M8 数字滚动降为直落终值**（数字不滚，但值必须正确）。触感与音效**保留**（减动效不缺反馈）。

**M7 三条例外规则（2026-11-09 补，苹果开发 发现降级分支会「变暗不缩放」后定的）**
1. **降级路径（iOS 17–25）必须也有按压缩放**——系统 `borderedProminent` 只变暗不动，等于「降级就呆板」，反向红线第 3 条在降级分支同样成立；
2. **降级路径只加缩放，不叠加自绘 tint/透明度变化**——系统已有变暗，再叠一层会双重反馈，看起来像按坏了；
3. **`reduceMotion` 时保留按压缩放，但时长降为 0（瞬时到位）**——按压反馈是「触感的可视化」，属功能反馈不属于装饰运动，不跟视差/庆祝一起降。这条与「减动效降 0.12s 淡入」不冲突：那说的是**装饰性位移**，按压是**即时状态**。

## 三、逐页动效规格（7 个维度，一页不漏）

图例：**进**=进场 · **滚**=滚动 · **按**=按压 · **数**=数字 · **转**=转场 · **庆**=庆祝 · **璃**=玻璃光影

### 3.1 首页

| 维度 | 规格 |
|---|---|
| 进 | Hero 视频带先淡入（M3 0.42）；标题区（eyebrow/巨号/建议）stagger 0.05 × 3 = 0.15 起，整串 ≤0.60s；数据条延迟 0.10 淡入；列表前 6 行 stagger 0.05（0.30s 内完成），**第 7 行起不做**（防廉价） |
| 滚 | Hero 视频带 M6 视差：上滚 0.3 倍速、缩放 1→0.96、淡出至 0.85；标题区正常速；到 200pt 时视频带完全淡出，内容接管（iOS 26 自动 scroll edge effect 提供顶部玻璃模糊） |
| 按 | 主操作 B1 M7 玻璃按压：scale 0.97 + 高光收起 + 阴影收紧；列表行 `BojiRowPressStyle` 底色 0.04 闪入 M1 |
| 数 | 巨号状态分 M8 滚动（如有变化），`状态分` 标签延迟 0.05 淡入 |
| 转 | 卡片→今日训练详情：M5 zoom 转场（把「开始练」按钮作为 source） |
| 庆 | 无（首页保持克制） |
| 璃 | 主操作玻璃常驻；滚动到顶部时 iOS 26 自动玻璃模糊；视频带自身不套玻璃（它上面只有品牌字与暂停钮） |

### 3.3 训练完成（全 App 唯一爆发点，5 段编排）

| 时间 | 段 | 内容 |
|---|---|---|
| 0.00s | 触感 | `BojiHaptics.milestone()` L4 + 音效 S4 `workout_done` |
| 0.00–0.52s | ① 品牌标 | M4 celebrate：scale 0.88→1 + 透明度 0→1 + `symbolEffect(.bounce)` |
| 0.05–0.35s | ② 标题 | 「辛苦了，训练已完成」Fade + 8pt 上移 |
| 0.15–0.60s | ③ 事实格 | 6 格 stagger 0.05（entrance 0.35 各格），整串 0.60s |
| 0.30–0.65s | ④ 数字 | 完成组/次数/训练量 M8 从 0 滚到目标值 |
| 0.55s | ⑤ 收尾 | 事实格细线 0.5pt 依次点亮（M2 0.20，stagger 0.03） |

**红线**：整个编排 ≤0.65s；运动元素同屏 ≤2（品牌标 + 数列算 2）；只此一次，不循环；减动效降为 0.12s 淡入 + 值直落。
**璃**：庆祝卡是全 App 唯一玻璃大卡（C1 24 圆角），出现时 0.42s 内从 1.02 缩到 1.00（M3）。

## 四、反向红线：什么算「干净但呆板」（返工判据）

| 反面样例 | 判定 |
|---|---|
| 页面直接 push，元素没有任何空间连续性 | ❌ 呆板——能 zoom 的必须 zoom |
| 所有动画都是 opacity 淡入淡出，没有位移/缩放/弹簧 | ❌ 呆板 |
| 数字直接跳变（0 组 → 3 组 无滚动） | ❌ 呆板 |
| 点按无任何视觉反馈（只有触感或都没有） | ❌ 呆板 |
| 玻璃按钮按下无变化（只有系统高亮） | ❌ 呆板——必须 M7 缩放 + 阴影收紧 |
| 训练完成页没有编排（一次淡入就完了） | ❌ 呆板——必须 5 段编排 |
| 滚动时整页一起平移，没有层次 | ❌ 呆板——Hero 必须视差 |
| 列表 20 行全部 stagger（拖沓又廉价） | ❌ 过度——最多前 6–8 行 |

## 六、像素化验收（测试验收可断言 / 可截图核）

- [ ] 页面转场：卡片→详情有 zoom（录屏可见元素生长，非直接切换）
- [ ] 首页滚动：视频带上移速度明显慢于内容（视差）
- [ ] 玻璃按钮：按下时尺寸缩小、阴影收紧（对比截图可量）
- [ ] 数字：组数/重量变化时可见滚动（非跳变）
- [ ] 训练完成：目标页出现后 0.65s 内完成「标→题→格→数→线」五段
- [ ] 列表：只有前 6–8 行有 stagger，后面不动
- [ ] 减动效全开：以上皆降为 0.12s 淡入 / 值直落，**功能与数值不缺**
- [ ] 无彩虹轮播、无无限闪动、无整屏缩放转场、一屏运动元素 ≤2
