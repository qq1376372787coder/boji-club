# 竞品交互范式拆解 + 5 条最低体验线（界面设计 · 2026-11-09）

> **证据口径说明**：本文是**桌面分析**，基于四款 App 的公开交互范式与 iOS 平台惯例，**非真机实测**（团队无这四款 App 的测试环境）。结论用于定「最低体验线」，具体像素与动效仍按我们的规格表。
> 对照物：我们的现状见《全局组件规格体系 v1》与《施工卡-甲1/甲2》；数据见台账 A 表 BUG-018~027。

---

## 一、四款 App 的「记录一次训练」路径

| App | 步数 | 路径 | 关键设计 |
|---|---|---|---|
| **Apple 健身** | **3 步** | 打开 → 「体能训练」→ 选类型 → 开始 | 没有「计划」概念，打开就能练；类型用大图标网格；开始即全屏计时 |
| **Strong** | **2 步** | 打开（首页即「开始训练」大按钮）→ 选/建 Routine → 开始 | **打开就是开始**，Routine 可留空；每个动作直接显示「+ 添加组」；数字键盘常驻 |
| **Keep** | **3–4 步** | 底部「训练」tab → 选课程/自由训练 → 选动作 → 开始 | 课程驱动为主，自由训练入口较深；有视频跟练 |
| **薄荷健康** | 3 步 | 首页 → 运动 → 选运动类型 → 开始 | 运动是附属功能，入口浅但品类少 |
| **我们（现状）** | **2 步** | 首页 → 「开始练」→ 训练中 | 已对齐 Strong 的最短路径 ✅ |

**结论**：我们的训练入口步数**已经是四款里最短之一**（2 步），不需要改。

## 二、四款 App 的「记录一餐」路径

| App | 步数 | 路径 | 关键设计 |
|---|---|---|---|
| **薄荷健康** | **3 步** | 首页「饮食」→ 拍照/搜索 → 确认 → 保存 | **拍照识别是核心**；搜索有热量库；确认页可改份量；保存后立刻显示「本餐 XXX kcal」 |
| **Keep** | 4 步 | 首页「饮食」→ 拍照/搜索 → 选食物 → 确认 | 与薄荷类似，但饮食是增值功能 |
| **Apple 健身** | — | **不支持饮食记录** | 只做训练与闭环 |
| **Strong** | — | **不支持饮食记录** | 只做训练 |
| **我们（现状）** | 4 步+ | 饮食 → 拍照/语音/手动 → 识别/编辑 → 保存 | 路径不短，但**识别等待与编辑面板层级多**，用户感觉绕 |

**结论**：我们步数不少，**问题在「感知步数」**——识别等待、编辑面板、底部面板三层叠加，让用户觉得绕。**该抄的是薄荷的「拍照后直接出结果卡，改份量在同一屏」**。

## 三、四条共性设计（值得抄的）

1. **打开即开始**（Strong）：首页最大的按钮就是「开始训练」，不需要先选计划。
2. **结果即时可见**（薄荷）：拍完照/选完食物，**当屏**显示「本餐 520 kcal」，不跳页。
3. **数字录入用系统键盘 + 步进器**（Strong/Keep）：重量次数直接数字键盘，不弹多层面板。
4. **空态给引导不给 0**（Apple 健身）：没记录时显示「开始你的第一次训练」+ 一个按钮，不显示 0 小时 0 分钟。

## 四、5 条最低体验线（写进验收，可判）

| # | 体验线 | 判定标准 |
|---|---|---|
| **L1** | **记录一次训练 ≤3 步可开始** | 从打开 App 到计时开始 ≤3 次点击；首页主按钮是第一步 |
| **L2** | **记录一餐 ≤4 步可保存** | 从入口到保存 ≤4 次点击；识别结果与份量编辑**同屏**完成 |
| **L3** | **每屏有且只有一个主操作** | 同屏 54pt 玻璃主按钮计数 == 1（可断言） |
| **L4** | **数字录入只走系统控件** | 重量/次数用原生 `TextField` + `decimalPad` 或系统 `Stepper`；无自绘键盘、无多层面板 |
| **L5** | **空态不摆 0、给一个动作** | 无数据时不出现 0 / 0% / 0 kcal；必须有一张引导卡 + 一个按钮 |

**这 5 条与现有规格的关系**：L1/L3/L4/L5 已写在规格里（行高/按钮/输入/空态各节）；**L2 是新加的**——「识别结果与份量编辑同屏」目前没有明确写，建议补进施工卡 §三（饮食页）。

---

## 五、给我们的三条改进建议（按性价比排序）

1. **饮食页抄薄荷**：拍照 → 结果卡当屏显示「本餐 XXX kcal」+ 份量步进器，**去掉底部面板这一层**（现在是面板套卡片，感知步数高）。
2. **训练页保持现状**：2 步开始已是最短，不要为了「更像 Keep」加深路径。
3. **空态全面对齐 L5**：全页面扫一遍 0 值（R02/R10 已改，其他页按同一口径）。
