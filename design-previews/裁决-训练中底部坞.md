# 裁决 · 训练中底部坞（界面设计 · 2026-11-09）

**问题**：mock §③ 的 58pt 玻璃坞（时间 + 完成这组）与既有 R28 休息计时环形大字坞（拍板 #3：环形 + 大字 + 4 个按钮）打架，两套不能并存。

**先认一个错**：mock §③ 那个坞，左边写「组间休息 01:24」、右边写「完成这组」——**把「休息态」和「组内态」两个互斥状态塞进了同一个坞**，这是我的稿子写错了。真正的分歧来源在这里，不是两份稿子风格不同。

---

## 一、结论：一套坞，两种形态，同高 58

**不做两个组件、不开两个高度。** 一个 `TrainingDock`，按「有没有休息倒计时」切换内容。高度恒定 **58pt**，玻璃胶囊，`.safeAreaInset(edge: .bottom)` 坐 tab 栏上方。

| 态 | 判定 | 左 | 右 |
|---|---|---|---|
| **组内态** | `restEnd == nil`（正在做组） | `已用时 12:34`（T2 28 等宽）+ 下方 `还剩 3 组`（T5 11） | **无按钮**——纯信息条 |
| **休息态** | `restEnd != nil`（倒计时中） | ◔ 环形 **24pt** + 倒计时 **T2 28 等宽**大字 + 下方 `组间休息`（T5 11） | **B1 44 玻璃「下一组」** |

**休息结束 / 跳过** → 坞自动切回组内态，播 S2 + 触感 `latch()`，文案「好了，下一组」在组内态左侧出现 1.5 秒后淡出。

---

## 二、为什么组内态不放「完成这组」

**完成动作的唯一入口 = 组次行的勾选圈**（`TrainingRegistrationViews` 现有），dock 不重复。

三条理由：
1. **动作要靠近目标**：用户盯着「80kg × 8次」决定完成，按钮就在这个数值旁边；放到屏幕底部等于让手来回跑（Fitts 定律）。
2. **dock 放完成按钮会**「不知道完成哪一组」——得额外维护 `activeSetID`，多一个状态源就多一处可能错（这个项目已经被「双状态」坑过：IOS-013 休息双状态）。
3. **同屏两个完成入口 = 没有主次**，正是「按钮抢戏」的老毛病。

> mock §③ 里那个「完成这组」之所以合理，是因为**那版稿子没有勾选圈**。现在实现有勾选圈，坞就该回归本职：**计时 + 休息**。
> **如果真机试用觉得完成动作不够显眼**，再讨论加回——但优先级是「避免双入口」，不是「多给一个按钮」。

## 二之二、代码现状（先看这个，免得改错地方）

`WorkoutView.swift:591-645` `restDock` 只有两个分支：
- `restPausedRemaining != nil` → 暂停卡（`:592-599`）
- `restEnd != nil` → 休息环形卡（`:600-644`）
- **两者都不成立（即组内态）→ 什么都不渲染**

**所以 mock §③ 那个「58 坞 + 完成这组」不是改造既有组件，是一条还不存在的新坞。** 施工时是**新增组内态分支**，不是改现有休息卡——这一点先对齐，能少返工一轮。

## 三、休息态的四个按钮去哪了（R28 重构）

现实现：环形 84pt + 大字 + 一排 4 个胶囊按钮（−15秒 / +30秒 / 暂停 / 跳过）——**四个等权按钮 = 没有主操作**，而且坞高约 160pt，压内容。

**改法**：
- **环形 84 → 24pt**（缩小成状态指示器，不再当主角）；倒计时数字升为主角（T2 28 等宽）。
- **四个按钮收成一个**：坞右侧只有 **「下一组」**（= 跳过/结束休息，B1 44 玻璃）。
- **−15秒 / +30秒 / 暂停** 收进 **点按倒计时数字弹出的系统 `Menu`**（原生，符合 iOS 习惯：点时间调时间）。
- **暂停态**（`restPausedRemaining`）保持：坞显示 `休息已暂停 · 剩 N 秒` + 右侧「继续」。这时「继续」就是该态唯一主操作。

**三联动不变**：最后 3 秒 `tick + S5 rest_tick` 同拍、数字微脉冲（减动效只留声震）、休息结束 S2 轻收——全部保留。

## 四、AX 大字号下的坞

坞高 58 是**固定**的，AX 下**不改高度、不改字号**（T2 28 是展示档，固定不缩放，与 §2.4 一致）。
- 左区文字若放不下（如「还剩 12 组」），**截断成「还剩 12 组」→ 只留数字与单位**（`还剩 12` + `组` 换行），不缩字号；
- 右区按钮文字「下一组」AX 下最多一字一行（「下一组」3 字，58 高内可容两行 15pt），**不缩字号**；
- 极端情况（AX5 且长数字）允许坞高在 AX 下升到 **72**，并**登记为例外**——但这是最后手段，优先用上面两条压排版。
