## 一、根因（先说清为什么破相）

**Hero 现在**：`ClubAIShell.swift:1166-1205`，卡高 **380pt**，视频 `scaledToFill` 铺满，文字直接压在上面，主标题 **52pt**。
**算术**：卡片宽 = 屏宽 393 − 页边 18×2 = 357pt，再减 `cardInset` 18×2 → **可用约 321pt**。52pt 中文字每字约 52pt → **一行只放得下 6 个字**。
**结果**：12 字的「今天的训练，已经为你准备好」必然折成 3 行，且中文按**字**断行（无空格），于是断在「已／经」中间；3 行 × 52pt = 156pt 高，从底部往上顶，正好压住视频人物脸。

**结论**：不是字重字距的问题，是**把大字号标题放在窄视频上**这个结构本身错了。改结构，不是改参数。

## 二、Hero 新版结构（三段式，苹果开发照此重写）

```
┌─────────────────────────┐
│ ⌐薄肌俱乐部             ⏸ │ ← 视频带 300pt（仅这两样文字/控件）
│                         │
│        [ 视频 ]          │   人脸安全区：整条视频带不放任何文字
│                         │
│ ░░░░░░░░░░░░░░░░░░░░░░░ │ ← 60pt 渐隐（clear → pageBackground）
└─────────────────────────┘
  今天 · 11月9日 周日          ← 页面背景上，11pt
  88                        ← 巨号 88pt（有数据时）
  状态正好，今天练上肢推        ← 15pt，一行
```

| 段 | 规格 | 关键约束 |
|---|---|---|
| **A 视频带** | 高 **300pt**（原 380），圆角 28 continuous，`scaledToFill` | 视频上**只允许**两样：左上品牌小字「薄肌俱乐部」12pt（内边距 16，距顶 16）、右上暂停钮 44pt 命中区。**禁止任何其他文字压视频** |
| **B 渐隐衔接** | 视频底 60pt 垂直渐变 `clear → BojiColor.pageBackground` | 视频与页面无缝，不要硬边 |
| **C 标题区** | 页面背景上，左对齐，上边距 14，左右页边 18 | **巨号数字与标题全部移出视频**，这是护脸的根本手段 |

**C 区内容顺序**：
1. eyebrow：`今天 · 11月9日 周日`（11pt / textTertiary）
2. 巨号：状态分数 `88`（**88pt / heavy / 等宽数字 / 字距 -3**）——数字不会断行，天然安全
3. 一句话：`状态正好，今天练上肢推`（15pt / textSecondary，**单行，超长截断用省略号**）

**没有健康数据时（空态降级，见第四节）**：巨号位置改放短标题 `今天练上肢推`（**40pt / bold / 字距 -1**，≤6 字），eyebrow 保持，一句话改「连接 Apple 健康后，这里显示你的状态」。

## 三、断行规则（全页面通用，必须写进组件）

| 规则 | 具体 |
|---|---|
| R1 字号与容量对照 | 52pt → 一行 ≤6 中文字；40pt → ≤7 字；28pt → ≤10 字；22pt → ≤13 字。**超过就必须主动断行** |
| R2 语义断行 | 长标题用 `\n` 按语义断开，写法：`Text("今天的训练\n已经为你准备好")`。**禁止交给系统随机断**（中文必断在词中间） |
| R3 兜底三件套 | 所有大标题加 `.lineLimit(2)` + `.minimumScaleFactor(0.9)` + `.allowsTightening(true)`，先缩再截 |
| R4 文字禁止压媒体 | **任何 >20pt 的文字不得压在视频/图片上**；只有 ≤15pt 的标注可以在图上，且必须叠护字渐变 |
| R5 单行上限 | 正文/说明文字单行最多 20 中文字，超过必须允许换行（`fixedSize(horizontal: false, vertical: true)`），**不许截断** |

## 四、空态观感方案（治「满屏 0 组 0g —」寒酸感）

**核心原则：没数据就不摆数字。巨号只能承载真实数据，否则排印会把「没有」放大成「很空」。**

| 场景 | 现在（破相） | 改成 |
|---|---|---|
| 全部无数据 | 0 组 / 0g / — / 暂未同步 一堆 | **不渲染数字格**。换成一张引导卡：系统符号（`heart.text.square` 44pt，textTertiary）+ 「连接 Apple 健康后，这里会显示你的睡眠、心率和训练」15pt + 一个主按钮「去连接」（44pt，`.borderedProminent` 胶囊） |
| 部分有数据 | 三项并列，缺的显示「—」 | **缺的项整块隐藏**，只显示有值的项；有值的项用数据块（数字 + 细线 + 标签） |
| 单点数据（如体重只 1 条） | 一个点撑趋势图 | **不画折线图**。改「已记录 1 次，再记 1 次就能看趋势」+ 当前值大数字。≥2 条才画图 |
| 数值标签 | 「还没同步到」被截成「还没同…」 | 窄容器一律用短标签 **「未同步」**（3 字）；宽容器才用「还没同步到」 |

**数字显示口径**：
- 有值：`88`（88pt）
- 无值：**不显示 0**，显示「未同步」15pt textTertiary + 不占巨号位置
- 分数量不足：显示「还差 1 项」而不是编分数

## 五、通用兜底规则（其余破相项，页面层统一执行）

| # | 问题 | 规则 |
|---|---|---|
| G1 | 「训练进行中」悬浮条压住 tab 栏 | **所有底部浮条/浮钮必须走 `.safeAreaInset(edge: .bottom)`**，让系统 tab bar 自动避让；**禁止**手写 `.padding(.bottom, 96/84)` 硬编码（`ClubAIShell.swift:981` 就是硬编码 96/84，直接删）。列表内容底部再加 `.safeAreaPadding(.bottom, 8)` 让最后一行不被浮条盖 |
| G2 | 饮食页「+记录饮食」大黑钮浮在内容上盖住早餐卡 | 浮钮不 overlay。改 `safeAreaInset(edge: .bottom)` 一条底栏（白底/玻璃条 + 主按钮），列表自然在它上方滚动 |
| G3 | 键盘上方整排重复「收起」 | `ToolbarItemGroup(placement: .keyboard)` 只能出现**一个**，且必须挂在**当前聚焦的输入所在视图**上。同一页面有多个 TextField 时，把 toolbar 提到**页面级一次**，不要在每行、每个输入框各挂一次（`TrainingRegistrationViews` 组次行是重灾区，逐行都挂了） |
| G4 | 身体页报错原文上屏 | 错误**不许**贴在概览卡上。规则：页面级错误 → 系统 `alert`；字段级错误 → 字段下方 12pt 红字；**未操作时不显示任何错误**（首次进入不显示「暂时未能完成操作」） |
| G5 | 三个大黑钮风格各异（继续练/继续训练/记录饮食） | 全 App **主操作统一**：全宽 54pt 胶囊、`.borderedProminent`、tint 品牌色。同屏最多一个主操作，其余降为 `.bordered` 或文字链 |
| G6 | 文本截断 | 见 R5；短标签 ≤5 字并 `lineLimit(1)`，说明文字一律允许换行不截断 |

## 五之二、大字号（AX）规则 —— 测试验收点名，必做

巨号排印在系统大字号下会被 `@ScaledMetric` 放大，88pt 可能变成 150pt+，必然二次破相。规则：

| 规则 | 具体 |
|---|---|
| D1 展示字不跟随系统缩放 | 巨号数字（88pt / 76pt / 52pt 这类展示排印）**不参与 Dynamic Type 缩放**——它们是版式元素，不是正文。写法：`.font(.system(size: 88, weight: .heavy))` **不加** `@ScaledMetric`，或显式限制上限 |
| D2 正文必须跟随 | 15pt / 13pt / 11pt 的说明文字**必须**跟随系统字号（可读性刚需），用现有 `bojiFont`/`bojiType` |
| D3 AX 尺寸下版式重排 | `dynamicTypeSize.isAccessibilitySize` 为真时：巨号降到 **48pt 固定**，标题区改纵向单列，三指标横排改**纵向列表**（每项一行「标签 值 单位」），不并排挤 |
| D4 不截断优先级 | AX 下宁可换行、增大行高、滚更长，也**不许截断**；`lineLimit` 只在非 AX 尺寸生效 |
| D5 复验方法 | 设置 → 辅助功能 → 显示与文字大小 → 更大字体，滑到最大档；逐屏看：有无词中断行、有无截断、有无压盖、有无横排挤出屏幕 |

**给苹果开发一句总结**：展示字固定尺寸 + 正文跟随 + AX 下改单列。这三条做完，BUG-018/023 在大字号下不会再犯。
