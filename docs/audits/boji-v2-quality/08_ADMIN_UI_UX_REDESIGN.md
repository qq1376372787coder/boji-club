# 管理后台 UI/UX 系统化重构

## 1. 目标与范围

把原来“14 个平铺入口 + 单行压缩 CSS + 统一白卡”的后台，重构为可长期扩展的运营控制台。  
保留服务端渲染架构（PHP + CSP、无前端构建链），避免为视觉重构引入新的运行时风险。  
**未改业务表单动作名称/CSRF/服务端校验**；所有页面继续使用原有 POST 动作。

## 2. 信息架构

一级导航按任务分组（仅显示当前角色可访问的页面）：

| 组 | 页面 |
|---|---|
| 运营 | 运营总览、俱乐部成员、月度成长季、发货管理 |
| 内容与奖励 | 徽章库、礼品库、消息中心 |
| Club AI | AI 服务中心、自动化任务、推送管理 |
| 系统与安全 | 存储与同步、系统状态、操作记录、系统配置、管理员与角色、安全设置 |

新增：
- **系统配置**：草稿 → 发布 → 版本 → 恢复为草稿；线上/草稿状态、差异提示。
- **管理员与角色**：角色边界说明、创建/停用/改角色/重置密码、最后一个超级管理员保护。

## 3. 设计系统

`admin/style.css` 统一变量：

- 颜色语义：`--bg/--surface/--ink/--muted/--line/--accent/--warn/--danger/--info` 及 soft 版本。
- 尺寸：`--radius-sm/--radius/--radius-lg`、`--sidebar-w:248px`、`--content-max:1480px`。
- 字体：系统中文栈；数字使用 tabular-nums；小标题 10–11px，页面标题 28px。
- 阴影：仅两级 `--shadow-sm/--shadow-md`，避免卡片堆叠阴影。
- 组件样式：卡片、指标、表格（sticky header、行 hover、数字对齐）、筛选栏、表单、开关、状态 badge、空态、详情、分页、公告/错误、登录页、徽章 3D 预览、配置 diff、版本记录、关注列表。
- 新增移动端菜单：`#nav-toggle` + label，默认折叠导航，避免 17 个链接占满首屏。

## 4. 页面结构规范

统一为：

1. 面包屑（组 / 页面）
2. 标题 + 一句话功能说明
3. 角色 chip + 日期
4. 核心指标/状态
5. 筛选/搜索
6. 主表格/表单
7. 结果反馈/审计入口

复杂配置使用 `two-col`：左编辑、右版本/说明；危险操作仍需 `data-confirm` 二次确认（保留原 app.js）。

## 5. 关键页面改造

### 运营总览

- 第一排：注册、完成引导、云端同步、训练活跃。
- 第二排：有效会员、今日 AI 任务、待履约申领、需要关注。
- 7 天训练图 + 本周记录。
- **需要关注**：注销失败、推送失败、待履约、未发布配置、备份状态；链接到对应页面。
- **最近管理员操作**：最近 6 条审计，显示操作者/时间/摘要。

### 系统配置

- 顶部“线上 vN / 草稿 vN + 状态点”；差异行展示待发布值。
- 只有草稿可编辑；发布按钮仅在 dirty 时出现；恢复历史只写入草稿。
- 版本记录显示动作/版本/管理员/说明/时间，支持恢复为草稿。
- 明确解释：只有 published 会被 `/config` 下发；密钥不在本页。

### 管理员与角色

- 新建默认“只读审计”，避免误建超级管理员。
- 角色边界展示人类可读页面名。
- 当前登录账号不能自我降级/停用；系统保留至少一个启用中的超级管理员。
- 重置密码即时失效旧会话。

### 消息中心

- 明确“测试发送”是真实 APNs 到一名成员的一台设备。
- 定时计划区域明确“仅保存草稿，尚未接入调度器，不会自动发送”，避免假象。
- 发送记录显示 sent/failed 和来源。

## 6. 响应式与可访问性

- 1440/1200/900/720 断点；900 以下侧栏变为头部，导航折叠；720 以下指标 2 列、表格横向滚动、表单单列。
- 所有按钮 `min-height:36px`、焦点环、`aria-current="page"`、`aria-label`。
- 状态不只靠颜色：badge 有文本，告警有“高/中”标签。
- `prefers-reduced-motion` 关闭徽章/过渡动画。
- 保留系统字体，不引入 Web 字体/外部图标依赖（CSP 仅 self）。

## 8. 保留与未做

- 保留原有徽章 3D/资产预览、成长季编辑、发货状态机、AI 实时轮询 JS。
- 未引入 React/Vue/构建链；没有为了视觉重构重写业务。
- 未实现深色模式（后台现在只有浅色）；未做骨架屏（服务端渲染页面，直接返回完整 HTML）。
- 未引入图表库；7 天柱状图为内联 SVG，避免额外 CSP/依赖。
- 未做管理员 2FA/SSO；见剩余问题。

## 9. 只读角色渲染

有查看权限但无写入权限的页面（如内容管理员看成长季、只读审计看成员）会显示“只读视图”提示，并通过 `display:none` 隐藏 POST 表单；服务端仍会拒绝写入（HTTP 403）。GET 筛选/搜索保留可用，避免“看似能点但提交 403”的死控件。

## 10. 回归风险

UI 重构涉及大量 HTML 结构调整，但动作名、字段名、CSRF、服务端处理未变；已用 16 页渲染 + HTTP 动作测试 + PHP 38 项回归覆盖。仍需在 staging 用真实数据（成员/成长季/图片/发货）做一轮人工操作回归。
