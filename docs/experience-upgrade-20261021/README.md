## 完成范围

1. 首页改为身体概览：按账号选择指标，自动收起缺失数据；只有一个指标时使用紧凑布局。展示本机健康数据与手动测量的来源、日期；当天没有新测量时仍可查询此前的最近实际测量。
2. 新增身体详情：体重、体脂、腰围、睡眠、静息心率、步数、活动能量趋势，7/30/90 天及自定义范围；可读取历史健康数据、查看设备和测量记录。
3. 保留原有 AI 健康分享确认。本机完整主要睡眠按醒来日组织，合并重叠时段、排除清醒间隔并单列其他睡眠；云端 AI 的原自然日 sleep 契约保持兼容。
4. 首页训练卡接入附件视频，使用兼容转码副本及静态封面；文字、进度和按钮覆盖其上。默认静音循环，离屏/后台暂停，减少动态效果与低电量时静态展示。
5. 首页、空白计划日、我的计划和空白训练页提供一致的安排入口；选择自己安排、AI、重复计划、模板或文字导入。首页携带日期，“提前练其他安排”直达对应流程。
6. 单日手动安排只作用于当天，不将同周其他日期写成休息日。
7. 自由创建默认隐藏描述、意图、模板、循环和逐组高级设置；支持批量选动作、自动保存草稿、真实日期标签、无冲突直接保存，有覆盖时预览。
8. 循环安排复用已经配置的实际训练日，不再向空白日期生成一批待配置占位日。旧占位草稿仍兼容读取与处理。
9. “我的计划”按采用操作组织，显示完整作用日期；提供结束未开始安排及归档。保护已开始、已完成训练及其他记录，并兼容没有版本记录的旧周期。
10. 动作与计划保存稳定归属，动作替换继续保留归属。计划取消使用不可变事件，客户端和服务端合并均保护并发真实训练，避免旧设备恢复已取消内容。
11. 资料保存默认保留现有计划；手动计划不被自动带去 AI。AI 用户也需主动选择才重新生成。
12. 新手引导新增直接自己安排，不依赖云端分析开关。
13. 恢复动作库静态图及 GIF；训练缩略图可按动作 ID 查询与缓存媒体，统一环境 URL 解析。移除全量关闭媒体的旧策略及与实际行为冲突的说明。
14. 动作推荐不再显示仅凭大类硬编码的通用发力节奏；个人动作和不可匹配动作仍保留准确的文字记录。
15. 使用已验证的 HTTPS 服务地址；支持通过 Info.plist 中 `ExerciseAPIBaseURL` 和 `AccountAPIBaseURL` 指定其他 HTTPS 部署地址。原正式域名本次环境无法正常解析/连接，不会继续让正式构建指向不可用的地址。
16. 校正训练中/未保存修改的入口文案，计划页“开始训练”统一启动本次计时；查看计划详情不自动开始计时。
17. 手动饮食模式不再出现拍照 AI 的说明。
