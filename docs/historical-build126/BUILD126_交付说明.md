# Build126｜统一资料中心与计划管理

版本 0.15.6（126），2026-10-26。基于已交付的 Build125。

## 现在从哪里使用

- 侧边栏 → **AI 对我的了解**：查看身体资料、目标与训练条件、自己填写的习惯偏好，以及 AI 的观察和纠正。原“我的 → 资料与目标”和营养资料入口也进入这里。
- 身体/目标卡右上角 **编辑**：分组修改。单项右侧菜单可以补充、修改、清空。多选用原生选择控件，数字用数字键盘。
- 训练 → **我的计划**，或右上角菜单 → **管理训练计划**：选择计划后可编辑，或带着该计划去 Club AI 调整。
- **编辑计划**：选训练日、改日期、添加/更换/移除/排序动作、修改目标组数与重量/次数/秒数。可以把当天草稿应用到本计划后续同星期的可编辑日期。
- **预览更改 → 确认保存**：核对修改前后安排，生成新版本，保留原版本与已开始/已完成训练。
- 计划右上角 **…**：完全未开始时显示“删除未开始的计划”；有训练记录时显示“结束计划，取消剩余安排”。归档只收起列表，不取消日历安排。

## 数据行为

1. 资料从服务端确认事实读取，与记忆独立加载；记忆不可用不会隐藏资料。未填写保持未知。
2. BMI 从适用的已确认身高与资料体重计算，不保存为独立记忆；资料体重、最近实测体重和目标体重分别显示、分别保存。
3. 修改资料重新计算当前营养参考，历史目标保留，现有训练计划默认不变。资料修改后的计划调整仍需用户预览确认。
4. 新增“我的习惯与偏好”文本；服务端每次构建 AI 上下文都读取当前确认值，清空后立即停止使用，不另存一份可独立生效的记忆副本。
5. 补齐昵称、其他器械、在家训练日的确认保存及兼容投影。在家训练日必须属于可训练日期。
6. 计划编辑按计划归属隔离，同一天的其他计划保留。已开始/已完成/过去训练只读。移动到已有其他安排或已开始训练的日期会拒绝保存。
7. 保存前同步并校验编辑基线；发现其他设备改动、计划结束或归档变化时拒绝覆盖。普通账号需联网完成同步才能确认计划编辑。
8. 一次本机持久化事务写入完整修改、新版本、旧版本关联和取消标记；目标组不计作实记。云端同步沿用既有同步机制，不能把本机保存等同于云端已确认。
9. 计划的 AI 入口携带原版本和按计划 ID 过滤的当前安排；旧计划也能引用当前内容。进入对话不会自动发送或直接修改日历。
