## 已确认的代码错误

配置使用 RevenueCat 旧版短项目 ID `9ce7d94a`，API v2 客户及权益响应返回规范项目 ID `proj9ce7d94a`。原策略直接严格比较字符串，因此把同一个项目误判为不同项目，内部错误为 `rc_invalid_customer`，对核验流程表现为 `rc_invalid_snapshot`。

修复文件：`account-server/public/revenuecat-snapshot-policy.php`。

增加严格、有限的项目 ID 格式兼容：仅将完整 8 位小写十六进制旧 ID 映射到对应的 proj 前缀 ID；不同项目、不同账户、不同商品、错误环境、退款、归档权益等条件仍保持原核验要求。没有取消项目校验或直接信任客户端会员状态。

## 最初不显示价格的原因边界

项目 ID 兼容错误位于购买后的服务器权益核验阶段，不能用它解释购买前的价格加载失败。

在没有更新客户端、没有修改付款页面的情况下，价格自行恢复；结合此前付费 App 协议尚未生效，推测与苹果协议/商品同步、系统商店会话或缓存刷新有关。Build 113 把不同方案加载错误统一显示为网络提示，没有记录可导出的错误细节，因此不能追溯证明最初的唯一原因。Build 114 已改善错误分类并提供只读诊断入口，但当前服务端修复无需安装该版本。
