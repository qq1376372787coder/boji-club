# BOJI CLUB 官网 + 法律协议网站

自托管的 **App 官网 + 协议/隐私政策中心**：**9 种语言 · 深浅色模式 · 移动端适配 · 在线编辑后台**。
纯 Python 标准库实现（`server.py` 单文件），零第三方依赖。

> 注意：使用前请阅读 **[DEPLOYMENT-GUIDE.md](DEPLOYMENT-GUIDE.md)**（部署指南，中文内容）——包含部署步骤、上线前必做事项、App 接入方式与 App Store 隐私标签对照表。

## 快速开始

```bash
python3 server.py --port 8765
# http://127.0.0.1:8765/          官网首页（落地页 + 真机截图 + App Store 下载按钮）
# http://127.0.0.1:8765/legal     协议中心
# http://127.0.0.1:8765/faq       常见问题
# http://127.0.0.1:8765/changelog 更新日志
# http://127.0.0.1:8765/admin     管理后台（初始密码见 data/ADMIN_INITIAL_PASSWORD.txt）
```

## 包含内容（9 种语言：简中/繁中/英/日/韩/泰/越/印尼/马来）

- **官网**：首页落地页（功能亮点、界面截图、下载 CTA）、常见问题、更新日志
- **协议 7 份**：用户服务协议、隐私政策、购买订阅与退款政策、账号注销说明、AI 服务说明、健康免责声明、关于我们
- `/sitemap.xml` 站点地图、OG/SEO 元信息、robots.txt

## 法律覆盖范围

以中国《个人信息保护法》《网络安全法》《生成式人工智能服务管理暂行办法》等为基础，
并覆盖：韩国 PIPA（含跨境传输专项披露与개인정보보호책임자）、日本 APPI、
新加坡/泰国/越南/印尼/马来西亚个人数据保护法、港澳台个人资料保护法制、印度 DPDP（Grievance Officer），
以及 App Store 订阅合规（自动续订明示、取消与退款、账号删除）。

## 运营者信息

在管理后台「站点设置」中维护（邮箱、域名、ICP 备案号、数据存储地、App Store 链接、官网公告条），
保存后自动替换到所有语言的协议正文占位符与官网页面。
官网首页文案（标语、功能列表）在 `seed/{语言}/home.json`，修改后重启服务生效。
